# FluentCanvas 5.0.2.0 验收记录

2026-11-18，在从 `zhh135/FluentCanvas` 的 `master` 分支检出的干净工作区（基线 `cd73065`）实施。交付分支为 `release/5.0.2-msix`。最终应用提交为 `60133a1`。构建主机为 Windows 11 Pro x64，使用 .NET SDK 11.0.100、MSBuild 18.12.2 与 Windows SDK 10.0.28000.0。

此页记录历史版本的验收结果。当前版本的环境要求和构建命令见[构建与发布](RELEASE.md)。

## 安装与交互

在隔离的 Windows 11 24H2 x64（内部版本 26100）上测试。宿主曾通过包身份实际启动 WinUI 诊断窗口。初版清单资源索引遗漏了 WinUI 资源，修复并重新运行后，窗口能显示 WPF 画布类型、WinUI 3、MSIX、架构和 .NET 版本，复制按钮具有可访问名称。[诊断窗口实图](store/screenshots/diagnostics-x64.jpg)

最终 x64 包已在干净系统中安装并从开始菜单启动，随后正常关闭。通过 Windows 文件关联冷开含 6 笔的中文路径 `.icstk`，在同一进程继续打开含 6 笔、1 个元素的 `.icart`。工具栏保存后重新打开的作品通过了笔迹和元素计数检查。还验证了实际笔输入、整笔擦除、Ctrl+Z/Ctrl+Y 的效果、稳定设置项在 LocalState 与重启后界面的一致性、开机启动状态关→开→关，以及应用内重启后产生新进程。WinUI 诊断窗口在该客机同样通过。在开启场景自动切换时，多指书写会随桌面/白板模式改变；独立的设置持久化检查使用双指旋转选项。[验收脚本和复现说明](SANDBOX-ACCEPTANCE.zh-CN.md)

商店展示用的[课堂白板实图](store/screenshots/whiteboard-x64.png)为 3050 × 1668，取自最终签名 x64 包运行的客机。图中讲义和可编辑笔迹均为本次验收生成的样例。诊断窗口的单窗截图供审核参考。

另开一台干净的 x64 来宾机，直接安装交付的双架构 MSIXBundle，Windows 自动选择 x64 5.0.2.0。系统报告实际白板窗口在 144 DPI（150% 缩放）使用 PerMonitorV2。通过 Windows 辅助功能接口关闭 Sentry，检查本地禁用标记，重新启动后界面仍为关闭，再启用后标记消失。

键盘与辅助功能抽查覆盖 Ctrl+Z、Ctrl+Y、设置开关和 WinUI 诊断窗口的「复制诊断信息」控件名称。完整键盘焦点顺序和屏幕阅读器朗读仍待人工验收。

桌面版 PowerPoint 的正向放映流程、数位笔压感、物理多显示器之间的 DPI 切换、ARM64 真机及真实商店身份升级需要相应环境。在 x64 来宾中已实测启用和关闭启动任务。由用户在系统设置中禁用、由组织策略阻止这两种状态仍待相应策略环境验证。验收期间，宿主机上的临时开发包仍有进程运行，已保留其注册和数据。它使用独立的 LocalTest 身份。
