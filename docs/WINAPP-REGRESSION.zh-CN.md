# 用 WinApp CLI 验证画板笔迹

这套回归在独立的 FluentCanvas 实例中操作画板。每个关键步骤都通过界面保存一份新的 `.icart`，随后独立读取其中的原生墨迹记录并核对校验和。可以分别检查界面上发生了什么，以及最终写入文件的内容。[回归脚本](../eng/Test-WinAppRegression.ps1) · [笔迹读取工具](../eng/Get-WinAppInkEvidence.ps1)

## 运行

在 Windows x64 上准备完整的 x64 自包含发布目录，其中应包含 `FluentCanvas.exe`、程序集和运行时。脚本使用 PowerShell 7.2 或以上版本、本机 WinApp CLI（已验证 0.8.0）和系统自带的 Windows PowerShell 5.1。先关闭已有的 FluentCanvas 实例，并让桌面保持解锁。书写和擦除需要测试画板能够获得前台焦点。

在仓库根目录执行以下命令，把示例路径替换为实际发布目录。

```powershell
pwsh -NoProfile -File .\eng\Test-WinAppRegression.ps1 -PublishDirectory 'D:\path\to\publish\win-x64'
```

结果默认写入 `artifacts/winapp-regression/<时间戳>-<随机标识>/`。也可以用 `-OutputDirectory` 指定一个尚不存在、位于发布目录之外的目录。

每次运行都注册一个唯一的测试包，复制发布文件，在系统临时目录中建立运行布局。测试实例使用自己的包数据目录和作品目录。测试清单移除了文件关联和启动任务，测试设置关闭了全局热键、演示联动和错误遥测。录屏与界面输入共享本次运行的 `WINAPP_UI_WORKFLOW_ID`。

## 检查内容

| 操作 | 通过条件 |
| --- | --- |
| 写两笔 | 保存文件中有两笔。两笔的平均压力分别与注入值 0.2、0.8 比较，允许绝对误差 0.08。笔数、低压和高压各有一项结果。 |
| 整笔擦除 | 擦除轨迹穿过第一笔，保存后剩余一笔，且其单笔几何哈希与原第二笔一致。 |
| 撤销与重做 | 撤销分别核对每笔内容及原排列顺序。重做后与擦除状态比较，再次撤销时重复核对内容与顺序。 |
| 增页与翻页 | 新页保存为零笔。第二页书写后，两页往返时各自的墨迹与离开该页前一致。 |
| 保存后重新打开 | 从第二页通过文件选择器打开第一份作品，等待应用记录新加载事件，再次保存并对比两份文件的笔数和有序几何哈希。 |

每笔的 `geometrySha256` 包含有序采样点、压力和所列绘制属性。整份笔迹的 `geometrySha256` 还保留各笔的排列顺序。例如，撤销后恢复了两笔但交换了顺序时，“每笔内容恢复”通过，“顺序保持”失败。读取工具支持 `.icart` 和 `.icstk`，并单列墨迹数据的哈希、点数、边界及压力范围。几何比较仅覆盖墨迹。

## 查看结果

先看 `session.json` 的运行状态与清理记录，再看 `results.json` 中每一条检查的详情。完整回归只要有一项失败就返回非零退出码。即使压感或撤销顺序超出预期，流程仍继续采集分页和保存证据。若必需步骤失败，后续依赖步骤可能尚未执行。启动阶段失败时可先查看会话错误和对应命令日志。

| 文件或目录 | 用途 |
| --- | --- |
| `documents/`、`ink-evidence/` | 各阶段保存的作品及独立解码结果，可复核单笔与整份笔迹的差异。 |
| `screenshots/`、`regression.mp4` | 对照当时的画板内容、工具和页码。 |
| `progress.txt`、`commands/` | 定位检查时间和对应的 WinApp 命令、参数、输出及退出码。 |
| `local-state/` | 查看归档的应用日志和测试设置。 |

压感结果适用于本次 x64 桌面的模拟输入路径。真实笔设备上的压感、延迟和掌压仍需在设备上验证。

## 调试与清理

`-PrepareOnly` 会准备并启动测试实例，保留注册包和运行布局供检查控件树。此时 `session.json` 的 `State` 为 `Prepared`，画板检查尚未开始。

完整运行结束时，脚本尝试归档本次日志、关闭所属进程、移除确切的测试包和临时运行布局，输出目录继续保留。手动结束 `-PrepareOnly` 会话时，先在该次 `session.json` 核对进程可执行路径、包全名、安装位置和 `RuntimeRoot`。确认进程和布局属于该次运行后，关闭该测试进程，按全名移除测试包，再清理对应的临时布局。
