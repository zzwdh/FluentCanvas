# FluentCanvas 隐私政策草稿

适用范围为 FluentCanvas 的 Windows 商店版。发布者应在上线前填写运营主体、有效联系邮箱、生效日期、诊断数据保留期限，并发布可公开访问的 HTTPS 页面。

## 白板和文件

应用在设备上处理笔迹、图片、媒体、选区和演示文稿放映状态。打开、保存和导入作品时由 Windows 读取或写入相应文件。截图功能会捕获当时显示的屏幕；启用放映截图或自动保存时，应用也会在相应时机写入文件。请在设置中选择适合课堂资料的保存位置。若该位置受 OneDrive 或其他同步软件管理，文件同步由该软件控制。

## 设置和本地日志

应用将设置、临时数据和运行日志保存在当前 Windows 用户的应用数据目录。日志可包含错误详情和文件路径。用户主动保存的作品和截图位于设置中指定的目录。开机启动由 Windows 管理，可以在应用或系统启动应用设置中关闭。

## 错误报告

白板进程默认启用 Sentry 错误报告。发生受监控的意外异常时，应用向 Sentry 美国区域的接收端发送异常类型、发生时间、调用方法、应用版本、运行方式、架构和 Windows 内部版本。网络服务在传输时会接触连接来源 IP。上传数据排除了原始异常消息、用户输入、文档内容、截图、完整本地路径和日志附件。这个版本没有启用会话回放或性能追踪。

在「设置 → 关于 FluentCanvas」取消勾选「向 Sentry 发送应用错误」，即可停止该白板进程的新错误报告；此选择在下次启动后继续生效。已发送的数据受发布者的保留设置和服务提供商条款约束。

## 网络服务与联系

商店版通过 Microsoft Store 获取更新。用户主动打开计算器网站、开源项目等外部链接时，默认浏览器会访问对应服务。

运营主体、联系方式、错误数据保留期限、适用的数据权利请求方式及政策生效日期，由实际发布者在发布前补全。[Sentry 隐私说明](https://sentry.io/privacy/) · [Microsoft 隐私声明](https://privacy.microsoft.com/privacystatement)
