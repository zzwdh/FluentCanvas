# FluentCanvas 隐私政策

本政策适用于 zzwdh 发布的 FluentCanvas 26.11.22.0 Microsoft Store 版，自本政策公开发布之日起生效。

## 白板、截图与课堂工具

FluentCanvas 在您的设备上处理笔迹、白板作品、您打开的文件和导入的图片或视频。您可以在「设置 → 保存」查看或更改保存位置，默认使用 Windows「文档」下的 `FluentCanvas` 文件夹。导入和打开作品时，应用可能在本地保存媒体副本或临时文件。

主动截图，或在启用相应功能后清屏、切换幻灯片时，应用可能截取一个或多个显示器当时显示的内容，其中可能包括其他应用的画面。截图保存在设置指定的位置或桌面。您可以在「保存」和「更多选项」中管理自动截图。

启用放映检测时，应用会在本机读取演示文稿的名称、路径和当前幻灯片等信息，用于识别放映和关联批注。自动收纳工具栏时，应用可能在本机读取当前窗口的标题与进程名称。抽选工具在本机处理您输入或导入的姓名、代号和替换规则。保存的名单可在抽选工具中修改或清空。如果在课堂使用，可用代号代替学生姓名。

## 本地保存与删除

应用设置、已保存的抽选名单和运行日志存放在当前 Windows 用户的应用数据目录。运行日志可能包含错误详情或文件路径。本地数据的访问由 Windows 用户账户及保存目录的权限控制。您可以通过设置管理自动保存与清理期限，也可以在文件资源管理器中查看、复制或删除保存的作品和截图。卸载后，保存在桌面、「文档」或其他自选目录的文件可能仍在，请按需手动管理。

若您将文件保存到 OneDrive 等同步目录或共享位置，相关服务会按您的设置处理文件。在应用内选择「复制诊断信息」时，版本、架构等信息会复制到 Windows 剪贴板，由您决定是否分享。

## 错误报告

白板主程序默认开启错误报告。发生纳入报告范围的异常时，应用通过 HTTPS 将诊断事件发送至 Sentry（Functional Software, Inc.）的美国区域接收端，用于定位和修复应用故障。

报告包含异常类型、出错的模块和方法、事件编号和时间、应用版本、安装环境、进程架构及 Windows 内部版本。应用在生成报告时排除原始异常消息、用户名、课堂名单、作品内容、截图、完整本地路径和日志附件。接收服务在建立连接时可接触来源 IP 地址。

Sentry 错误事件自接收之日起保留 **7 天**。您可以在「设置 → 诊断与隐私」关闭「向 Sentry 发送应用错误」。设置会在重启后继续生效，关闭后应用停止生成新的错误报告，您仍可使用白板、批注等功能。对已发送的事件，您可按下文的联系方式提出查询或删除请求。[Sentry 隐私政策及联系方式](https://sentry.io/privacy/)

## Microsoft Store 与其他服务

Microsoft Store 处理本应用的下载、更新及您主动提交的评分和评论。您可以在「设置 → Microsoft Store」关闭应用启动时自动检查并下载更新。使用商店时，您的相关信息由 Microsoft 按其隐私声明处理。[Microsoft 隐私声明](https://www.microsoft.com/zh-cn/privacy/privacystatement)

您主动打开 Desmos 等外部网站或启动第三方工具时，相关服务按其自身的隐私政策处理您的信息。

## 您的权利与联系方式

您可以通过 FluentCanvas 商店商品页公布的开发者支持渠道联系 zzwdh，询问个人信息的处理方式，或在适用法律规定的范围内申请查阅、复制、更正、删除您的个人信息。若请求涉及某次错误报告，可提供大致发生时间、应用版本或已知的事件编号，帮助我们查找。联系时请避免发送学生名单、课堂截图或其他与请求无关的个人资料。[FluentCanvas 商店商品页](https://apps.microsoft.com/detail/9PK5DXN35FD3)

我们会在应用功能或数据处理方式发生变化时更新本政策，并在公开的政策页面公布更新内容。
